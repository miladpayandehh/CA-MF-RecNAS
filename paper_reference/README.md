# Manuscript-reported reference tables

Every CSV in this directory is a transcription of aggregate values stated in the supplied CA-MF-RecNAS manuscript. These are **not** outputs generated by the repository implementation. They are retained as comparison targets and as a machine-readable record of what the manuscript reports.

The source manuscript reports means over ten runs in several tables, but it does not include per-seed observations. Consequently, confidence intervals and paired significance tests cannot be independently recomputed from these aggregate CSV files.

Files include dataset statistics, ML-1M benchmark results, closest-method comparison, fuzzy and operator ablations, calibration retention, few-shot and sparsity protocols, scalability, architecture patterns, diversity, and end-to-end cost.

The `closest_methods.csv` file deliberately preserves the stated `0.32` search-cost value and flags its unit ambiguity: the table header uses GPU-hours, while the abstract/conclusion and cost-accounting discussion label search cost as GPU-days. See `docs/REPRODUCIBILITY_AUDIT.md`.
